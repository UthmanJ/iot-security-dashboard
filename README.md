# IoT Device Security Dashboard

A full-stack web application that simulates real-time monitoring of IoT devices, tracking security posture, firmware status, and alerts across a fleet of connected devices.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB (Mongoose)

## Status
🚧 In development

## Features (planned)
- Device inventory with live status (online/offline)
- Automated risk scoring based on firmware age and known vulnerabilities
- Real-time security alerts feed
- Dashboard summary metrics
